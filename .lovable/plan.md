# Plano: Sistema de gestão de estoque e campanhas

## Objetivo
Criar somente o frontend em React de um painel administrativo para gerenciar estoque, unidades móveis, locais de coleta, cidades, parcerias e campanhas.

## Experiência
- Menu lateral para alternar entre as seis áreas.
- Visão geral inicial com indicadores e atividades recentes.
- Cada área terá sua própria tela, tabela, busca, filtros e ações de criar, editar, visualizar e excluir.
- Formulários em janelas modais com validação básica e confirmação antes de excluir.
- Dados de demonstração mantidos apenas durante o uso da página, sem banco de dados.
- Layout adaptado para computador e celular.

## Direção visual
- Paleta clara em azul e branco, com contrastes funcionais para estados e alertas.
- Aparência de sistema operacional: organizada, compacta e fácil de escanear.
- Tipografia limpa, ícones consistentes e movimentos discretos.
- Cada área identificada por título, descrição e controles próprios, mantendo o mesmo padrão visual.

## Detalhes técnicos
- React com TypeScript e rotas do projeto.
- Componentes reutilizáveis para navegação, tabelas, filtros, indicadores, formulários e confirmações.
- Design tokens centralizados para cores, tipografia, bordas e sombras.
- Metadados próprios em cada rota pública.
- Sem autenticação, banco de dados ou integrações externas.
